需要开启开发者模式：Edge 加载本地扩展时开启一次即可，之后日常使用不用再切换。

本地扩展不会自动更新；有新版本时重新下载并重新加载即可。

三步安装

  1. 下载并解压 zip，确认 manifest.json 直接在解压后的文件夹里。
  2. 打开 edge://extensions，开启「开发人员模式」→「加载解压缩的扩展」→ 选择这个文件夹。
  3. 刷新学习通页面，点扩展图标打开侧栏，在「API 设置」里填一次地址、Key、模型并保存。
侧栏显示「已连接」后即可开始。

安装后检查

侧栏显示未连接：刷新学习通页面，或点侧栏里的「重连」。
API 显示未配置：填一次 Key 保存；之后自动下一题或刷新页面不需要重配。

需要自备 API Key；题目和图片会发送到你配置的模型接口。
