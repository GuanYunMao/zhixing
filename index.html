四步安装

  1. 在 edge://extensions 删除旧的两件套扩展，并在 Tampermonkey 里删除/停用 4.2.7 用户脚本。
  2. 把 zip 解压到固定目录，确保 manifest.json 直接在该目录里。
  3. 打开开发者模式 → 「加载解压缩的扩展」→ 选这个目录。
  4. 刷新所有学习通页面，点扩展图标打开侧栏；在「API 设置」里填一次地址、Key、模型并保存。
加载完成、侧栏显示「已连接」后，自动下一题、跨题继续、跳过已做题、全部完成自动暂停才可用。

自动更新：这里没有

本地解压加载的扩展不会自动更新。Edge 的自动更新只对商店扩展或企业策略分发的扩展生效；把 zip 放在 GitHub Pages 上不会让浏览器自动替换它。

现在怎么更新下载新 zip → 覆盖原目录内容 → 在 edge://extensions 点「重新加载」→ 刷新学习通页面。API 配置存在 chrome.storage，通常能保留。
真正自动更新上架 Edge Add-ons 商店，或由管理员用企业策略下发。商店需要开发者账号、审核和隐私说明；这类自动答题脚本大概率拿不到上架资格。

安装后先检查

侧栏显示未连接

刷新学习通页面；点侧栏的「重连」；确认扩展在 edge://extensions 里没有报错。扩展 reload 后旧标签页必须刷新一次。

API 显示未配置

单扩展不读取旧 Tampermonkey 的 GM 存储。填一次 Key 保存；之后自动下一题/刷新不需要重配。Key 留空保存会保留已存 Key。

页面里还有旧面板

说明旧用户脚本还在跑。停用/删除 Tampermonkey 的 4.2.7，刷新页面，只保留这个扩展。

分享链接

把页面地址发给别人；安装包就在同目录，不需要登录 GitHub。

边界与安全

不需要Tampermonkey、用户脚本、右键“在侧栏中显示”。单击扩展图标即可打开侧栏。
需要Edge/Chromium 114+、开发者模式、可用于 OpenAI 兼容接口的 API Key；题目和图片会发往你配置的模型服务商。

API Key 保存在扩展的 chrome.storage.local，并会在页面 MAIN world 的内存缓存中出现；不写页面 localStorage。不能接受这个前提就不要安装。真实学习通定制页、iframe、公式和考试题型仍需自己验证。
