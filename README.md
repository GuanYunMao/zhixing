# 知行 · 网课助手 4.2.8

单扩展版：页面逻辑、侧栏和 API 设置都在一个 Edge 扩展里。

## 安装页

<https://guanyunmao.github.io/zhixing/>

## 安装

1. 下载并解压 `zhixing-4.2.8-single-extension.zip`，确认 `manifest.json` 直接在解压后的文件夹里。
2. 打开 `edge://extensions/`，开启开发者模式，点「加载解压缩的扩展」，选择这个文件夹。
3. 刷新学习通页面，点扩展图标打开侧栏，在 API 设置里填地址、Key、模型并保存。

## 更新

本地加载的扩展不会自动更新；有新版本时重新下载、替换原文件夹，再在 `edge://extensions` 点「重新加载」。
